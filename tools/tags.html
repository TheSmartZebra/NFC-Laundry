Laundry Tag Sheet

Generates the printable QR tags and the NFC URL list for all 12 machines.

Paste the URL wrangler deploy printed (or your custom domain). Everything runs in this page — nothing is uploaded. Print at 100% scale, then cut along the dashed lines.

Writing the NFC tags

  1. Install a tag writer (NFC Tools on Android/iOS works fine).
  2. Choose Write → Add a record → URL/URI.
  3. Paste the machine's URL from the table below, hold the phone to the sticker, write.
  4. Lock the tag read-only if the app offers it, so it cannot be rewritten by a passer-by.
  5. Stick the tag on the machine and the printed QR card next to it — the QR is the fallback for phones without NFC, and for anyone who would rather scan than tap.
